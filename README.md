# Aayushi Pandey — Portfolio

Recruiter-facing portfolio website for Aayushi Pandey.

## Publish with GitHub Pages
1. Upload `index.html`, `README.md`, and `Aayushi_Pandey_Resume.pdf` to the root of the `aayushi-portfolio` repository.
2. Commit the changes to the `main` branch.
3. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.

The résumé download button expects the PDF filename to remain `Aayushi_Pandey_Resume.pdf`.
