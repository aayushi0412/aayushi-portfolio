# Publishing Aayushi's portfolio

## Files
- `index.html` — the animated, responsive portfolio website.
- `PROFILE_README.md` — concise content to use in your GitHub profile repository README.

## Publish the website with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `aayushi-portfolio`.
2. Upload `index.html` to the repository's root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to finish deploying. The expected address is:
   `https://aayushi0412.github.io/aayushi-portfolio/`
7. Open the address and test the page on both desktop and mobile.

## Update your GitHub profile README

1. Open the special profile repository named `aayushi0412` (the repository whose name matches your GitHub username).
2. Replace its current `README.md` content with `PROFILE_README.md`.
3. Keep the Portfolio Website link as shown once the website is live. If GitHub Pages gives a different URL, update that link to the exact published address.

## Final checks before sharing with recruiters
- Confirm every project repository is public and opens correctly.
- Check all metrics and dates.
- Test the email and LinkedIn links.
- Add a PDF résumé link if you want recruiters to download your résumé.
- Do not publish confidential internship/customer information or non-public company data.
